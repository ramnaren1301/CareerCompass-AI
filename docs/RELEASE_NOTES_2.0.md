# PathwayOS 2.0 Release Notes — Career Buddy Redesign

## Why this is a major release

Versions 1.x exposed a chat next to independent Overview, Degree, Career, Opportunity, Roadmap, Approval, and Tool Studio screens. Although they shared state, the experience still behaved like several products and displayed far more information than a student needed at any one time.

Version 2.0 removes that product model from the primary application.

## New continuous experience

- One persistent conversation workspace
- One active decision at a time
- Nine dependent steps
- Future steps locked until relevant
- Completed choices summarized as a compact pathway trail
- Earlier choices revisitable with dependency-aware recalculation
- No default Machine Learning Engineer goal
- No full scholarship, internship, research, course, or tool directories in the main journey

## Focus limits

- 3 career directions
- 3 roles initially
- 1 next semester
- 3 skill gaps
- 1 learning action
- 1 proof project
- 2 experience options
- 2 funding options
- 5 final milestones

## Choice-driven behavior

- Role drives every later recommendation.
- Priority changes planning and recommended proof type.
- Academic route creates a concrete bridge, program-change, or advisor checkpoint.
- Workload changes the semester simulation.
- Skill selection drives the learning and proof deep dive.
- Experience and funding selections are the only opportunities retained in the roadmap.

## WebMCP and approvals

All 33 tool contracts remain available, but execution history is moved behind an activity drawer. The degree-plan write remains inline and approval-gated.

## Removed from the active build

- independent dashboard renderer
- previous persistent-chat intent router
- multi-screen browser regression suites
- old multi-screen mockups and embedded workflow guide
